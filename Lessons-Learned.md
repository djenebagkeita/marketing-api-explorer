# Lessons Learned

## Lesson 1: Understanding Modern Data Architecture

### Before
I thought CRMs, data warehouses, and Tableau all served the same purpose.

### What I Learned
- CRM = Run the business
- Data Warehouse = Understand the business
- Tableau = Explain the business

### Why This Matters
Separating operational systems from analytical systems keeps CRMs fast while allowing analytics teams to perform deeper reporting and analysis.

---

## Lesson 2: APIs

### What I Learned
An API is the official interface between systems. It validates authentication, authorization, and requests before returning only the data or actions a user or application is permitted to access.

---

## Lesson 3: Postman

### What I Learned
Postman began as an API request and testing tool but has evolved into a complete API development platform used for designing, testing, documenting, publishing, collaborating on, and maintaining APIs.
